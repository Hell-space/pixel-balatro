# 1.4.0 玩法与取舍

## 商店工坊

每次进入商店可以做一次改造，刷新商品不会重置次数。先在“工坊”选服务，再从整副牌中选择目标，确认前不扣钱。

| 服务 | 原价 | 效果 |
| --- | ---: | --- |
| 删去一张牌 | $4 | 永久移除指定牌，降低杂牌比例；至少保留 5 张 |
| 复制一张牌 | $6 | 原牌保留，新牌完整继承点数、花色、强化、版本、蜡封 |
| 强化一张牌 | $5 | 指定牌计分时额外 +30 筹码，可叠加 |

商店折扣同样作用于工坊。复制产生独立的新牌，会计入“全息图”等已有新增扑克牌效果；强化只改选中的那张牌。删牌会减少牌库总量，过度精简也可能更早抽空。工坊不能在开包或出牌中使用。

## Boss 战利品

单人击败 Boss 后，进入商店前选择一项：

- $8：可以立即购买商品，也能提高之后的利息。
- 自选一个可用牌型升 2 级：默认选本局用得最多的牌型，可以切换。未打出过的隐藏牌型仍保持隐藏。这是牌型升级，不会增加星球牌使用计数。
- 两次免费工坊操作：可以跨店保存，但每店仍只能改造一次。确认操作时优先使用免费次数。

三个奖励不能兼得。选择状态可以保存、退出、续局；不会重新抽取或重复领取。第八底注先显示胜利，继续无尽后再选择奖励。旧存档不会补发过去已打败的 Boss 奖励。
