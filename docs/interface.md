# 界面与操作

1.6.0 沿用绿毡、奶油纸牌与黄铜配色，统一游戏内选择和弹窗。本轮不改变牌型、计分、经济或 Boss 奖励数值。

## Boss 升级

击败底注 Boss 后，在战利品的升级项点击当前牌型，打开游戏内选择面板。每一行显示当前等级、升两级后的等级，以及筹码和倍率的前后值；已选择项有边框和勾选标记。特殊牌型仍需本局打出后才出现。

点击一行只更换牌型并返回战利品，不领取、不扣钱。再点击“升至…级”才领取升级奖励，与金币、免费工坊两个奖励互斥。未领取时退出或刷新会保留已选牌型。返回按钮、Esc 和 Android 返回键关闭选择面板，不领取奖励。

桌面可用方向键、Home/End 移动焦点，Enter 选择；Tab 保持在当前弹层。手机长列表内部滚动，返回操作保持在底部。

## 设置和工坊

菜单计分速度直接选择 1×、2×、4× 或立即，当前档位高亮。音乐、音效分别开关，设置沿用原来的保存键。工坊使用五个花色按钮筛选，切换花色会清除此前选择，避免确认改造已被筛选隐藏的牌。

## 信息界面

- 牌型表按行显示名称、等级、筹码 × 倍率、示例与本局次数。
- 牌库按花色分组，点击花色可单独查看。数字是“待抽 / 牌组总数”；变暗表示本盲已抽出，破折号表示牌组没有该牌，黄铜边框标记底牌。
- 本局信息按金币、计分、牌组和成长资源分组，优惠券单独列出。
- 菜单、开局、图鉴、持有牌和结算等长内容在正文区域滚动，标题及主要操作保持可达。

存档、设置、通关记录和所有已有玩法继续保留。具体构建与实际设备检查见 [验证记录](verification-1.6.0.md)。
