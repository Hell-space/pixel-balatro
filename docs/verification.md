# 1.1.0 验证记录

验证日期：2026-11-06。运行环境：Windows，Node.js 24.18.0，Python Playwright，已安装的夸克浏览器。浏览器使用无头隔离会话；手机尺寸和触摸输入由浏览器模拟，不等同于 Android 或 iOS 真机验收。

## 构建与规则

- `npm run build` 生成自包含 `balatro.html`；`npm test` 确认输出与源码一致。
- 九种基础牌型、参与计分的牌数、A2345 顺子、不允许 KA234 跨越顺子。
- 万能牌的同花判定、牌型升级、燧石 Boss 对基础值的影响，以及首底注的三个目标分数。

## 浏览器流程

`tests/browser_smoke.py` 固定随机种子并关闭测试中的音频，操作通过按钮、鼠标或触摸事件完成；没有直接修改游戏状态来达成胜利。测试独立计算普通牌的预期得分。

| 场景 | 验证内容 |
| --- | --- |
| 390 × 844 手机竖屏 | viewport 与屏幕等宽，无整页横向溢出；选牌上限、长按、弃牌、计分、商店和续局 |
| 360 × 640 手机短屏 | 两排手牌与主要按钮可见；商店实际触摸滑动后可购买；操作栏固定可达 |
| 844 × 390 手机横屏 | 牌桌重排，单排手牌和按钮可操作；长按与核心对局流程 |
| 1365 × 768 桌面 | 鼠标选牌、菜单、两对与葫芦计分、首关结算、商店购买、下一盲注 |
| 新手教程 | 短屏和横屏的 10 个步骤；高亮中心不被教程框覆盖，前进、后退和完成可用；横屏长正文可触摸滚到末尾 |
| 存档 | 弃牌后、出牌后、结算、商店购买后、下一盲注的刷新恢复；出局后刷新与盲注前重试 |
| 便携 HTML | 直接以本地文件打开，完成选牌、弃牌、计分及刷新续局 |
| Node 入口 | `/` 和 `/balatro.html` 返回相同游戏内容 |
| 多人对战 | 两个隔离浏览器会话创建/加入同一房间，配对后同步对手当前关卡与分数状态 |

第一关实测弃掉 1 张牌后，打出两对 **116 分**和葫芦 **296 分**，总分 **412**，达到 **300** 分目标；进入商店买小丑牌后继续下一盲注。失败分支通过四次较弱出牌得到 **43 分**，随后刷新并回到小盲注前的保存点。

弃牌并正常刷新续局后，以只读检查确认手牌和剩余牌库中的对象均引用原始牌组的对应对象，ID 各自唯一，手牌与剩余牌库无交叉。这样后续强化手牌仍能正确反映到整副牌组。

## 已知边界

- 未在实体手机上验证。不同浏览器对直接打开本地 HTML 和本地文件存档的支持可能不同。
- 未完整打通全部 8 个底注，未穷举所有小丑、卡包、塔罗、优惠券与 Boss 组合。
- 多人验证覆盖本地双客户端配对和状态同步；未验证公网/实体设备连接、完整对决赛程或弱网体验。
- 计分动画和卡包选择中途退出，恢复到该动作开始前最后一个稳定状态。
- GitHub Pages 只提供单人静态页面；联机依赖单独运行的 Node 服务。

运行回归会在本地 `.qa/` 生成 JSON 和实际页面截图；这些临时产物不纳入 Git。页面源码、便携文件和测试脚本一起维护。
