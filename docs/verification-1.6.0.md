# 1.6.0 界面验证

日期：2026-11-07。本轮统一游戏界面，操作说明见 [界面说明](interface.md)。保留关卡目标、牌型计分、经济和全部玩法；存档格式与 Android 宿主不变。

## 规则与结构

`npm test` 47 组通过，包含原 44 组与新增 3 组升级选项、返回/续局、筛选安全回归。独立验证 5 级对子显示升到 7 级、筹码 70→100、倍率 6→8；生成选项不改状态，隐藏牌型按原规则解锁，选择不领取、最后只升级一次，切换工坊花色清除已隐藏的旧选择。既有出牌、计分、底牌、卡包、悬赏、多人服务与存档回归均通过。

生成 HTML 标签配对与 175 个 ID 唯一性检查通过，核心页面原生 select 数量为 0。旧浏览器回归脚本已兼容新按钮，仍可检查旧版原生选择框；没有以删除断言代替实际操作。本轮未调整玩法数值或重复运行历史的完整对局模拟。

## 浏览器

25 个唯一用例的最新结果全部通过：r3 上 4 项 Boss 选择器，最终 r4 上其余 21 项。r3 HTML 为 239,489 字节，SHA-256 `5fce5b85f96b3bc3e6f851144cb8d1e04ee494bacd470b8fffe7155ac9037f40`；r4 为 239,071 字节，SHA-256 `66521a8c919c61ebddc82f7b28ff2f557dce833272b15bcc800fa1168e8ec6c9`。r4 只新增进入次级弹窗清除旧提示，并删除不再使用的 select 样式，没有更改布局或奖励规则。

- 320×568、390×844、640×360 和桌面四视口的 Boss 选择器，覆盖自然可选 9 种、全部解锁 12 种与 75 级数值。场景为真实跳过两次后进入 Boss，注入四张 A 后实际出牌获胜；稀有解锁和高等级为明确夹具。
- 每项等级、筹码和倍率前后值与独立计算一致；实际滚到列表末项，方向键/Home/End、Tab/Esc、网页模拟 nativeBack、快速双击、选择后刷新和只领取一次均通过。网页 nativeBack 不等于 Android 硬件返回键。
- r3 的旧 Boss 提示曾短暂遮住横屏返回按钮下缘，虽然不拦截点击，仍修正为打开次级弹窗时清除旧提示；r4 同场景复验时返回完整可见、可点击。
- r4 遍历标题与继续、开局/选盲/备战、商店五分类、工坊花色、持有牌、卡包、四档速度、信息、牌型表、牌库筛选、图鉴和记录、底牌、现金结算与失败。十手牌、6 小丑/3 消耗槽、Boss/节奏/悬赏和大分数密集夹具在四尺寸下通过。
- 胜利界面使用第 8 底注与目标 1 的临界状态后实际出牌触发，不作为完整通关。多人大厅、取消离开、确认离开与对方结果用两个真实本地客户端检查。

奖励列表实际触摸滚到末项；其他长面板核对内容尺寸、可见范围、筛选与固定操作，没有逐一触摸滚到末项。手机尺寸为模拟触摸，桌面为鼠标/键盘。使用隔离无头夸克，测试浏览器与候选服务已结束。

r2 最初因未等待 150ms 入场动画结束就测按钮位置而误报；测试等待 220ms 后 r3 通过。r4 初次小屏卡包用错取消按钮选择器而超时，改为实际按钮后通过。正常后续操作遵守现有 350ms 防连点期，没有削弱生产保护。失败和修正均保留。
