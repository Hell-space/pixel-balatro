# 袖中底牌

单人对局的牌桌上点“底牌”即可使用。每个盲注可存入一次、换回一次；开局时不必选择模式，不占小丑或消耗牌槽位。

1. **藏入**：选一张手牌放入底牌，立即从现有牌库补一张。
2. **换回**：之后选一张手牌，换回已藏底牌。换出的牌本盲注不再抽到。

两步均不消耗金币、出牌或弃牌次数。取消选牌没有任何消耗。只存入也可以，不要求一定换回；进入下一盲注时，全部未销毁的牌回到牌组，底牌次数重置。

底牌保留原本的点数、花色、强化、版本和蜡封。暂存时不属于手牌，因此不触发钢铁、红蜡封重复留手等效果，也不参与黑板、举拳等按当前手牌判断的小丑。换回后恢复正常效果。底牌不复制牌、不增加牌组张数，塔罗只作用于实际选中的手牌。

牌库为空时不能藏入补牌，已经藏好的底牌仍能换回。计分中无法操作底牌；藏入和换回均自动保存，计分中途退出会回到本次出牌前的稳定状态。1.4.0 及更早存档默认尚未使用底牌，多人保留原有规则。

底牌可保留凑顺子或同花的关键牌，也可把高强化牌留给后续出牌。暂存钢铁牌会失去其留手加成，换牌时应同时比较手牌预览。
