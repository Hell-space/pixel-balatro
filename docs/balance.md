# 1.3.0 平衡记录

日期：2026-11-06。目标是让首轮有可靠的构筑入口，并保留后期准备 Boss、取舍经济与乘倍率的压力，不把所有牌组或难度调整成相同体验。

## 具体调整

- 首个普通商店固定一个 $4 的普通计分小丑候选，仍需购买；刷新不反复保证这项优惠。商店和小丑包的两张候选去重。
- 之针只有一次出牌，目标从普通 Boss 的 2 倍底分降为小盲注底分；底注 3 起才出现。独眼、燧石也从底注 3 起出现；巨墙、流水、面具从底注 2 起出现。
- Boss 使用不重复候选轮换，单人与多人都遵守分阶段候选。候选用尽后再开新轮。
- 赏金猎人改为按剩余弃牌赚 $2/次、上限 $6，价格 $4，形成与黄金小丑稳定 $4 收益不同的选择。
- 新增顺子/同花/对子乘倍率、留手黑色牌、资金与塔罗成长路线；补齐梅花/方块转换和点数提升，让牌库改造支持更多牌型。
- 蓝组额外出牌有长期收益，因此起始资金改为 $0；金组起始金币定为 $10。绿色牌组不再抽到没有效果的利息券。
- 红注和金注保留首底注分数，从第二底注提高目标；金注另减少一次弃牌。旧存档不会重算已经获得的基础次数或资金。

## 完整流程模拟

使用 `scripts/simulate-balance.cjs`，每个种子从新局开始，调用实际盲注、抽牌、出牌、商店、结算与胜负函数，直到第八底注 Boss 胜利或正常失败。没有改小目标、增加金币、强制通关或读取牌堆下一张顺序。

自动玩家枚举当前手牌的 1–5 张组合，用预期分数选牌；弃牌仅用已知剩余牌的组成采样，商店用固定样本评估小丑并调整顺序。它不优化塔罗、跳盲和所有长期构筑，不能代表真人胜率。样本数较少，通关率接近也不表示难度完全相同。

以下为每种配置固定种子 1–24 的最终结果：

| 牌组 / 难度 | 通关 | 到达底注 8 |
| --- | ---: | ---: |
| 红色 / 白注 | 16/24 | 18/24 |
| 蓝色 / 白注 | 19/24 | 20/24 |
| 金色 / 白注 | 17/24 | 18/24 |
| 绿色 / 白注 | 20/24 | 21/24 |
| 黑色 / 白注 | 16/24 | 17/24 |
| 红色 / 红注 | 16/24 | 17/24 |
| 红色 / 金注 | 14/24 | 16/24 |

另测经典旧规则 48 个种子，通关 36 局。合计 216 局最终配置模拟。蓝组调整前同样 24 种子通关 22 局、金组为 21 局；调整后分别为 19、17 局。绿色移除无效利息券后为 20 局，原先为 18 局。

初始 1.2.0 的 16 种子基线为 4 局通关；1.3.0 同经典开局的前 16 种子为 14 局。候选池改变会使后续随机序列走向不同，不能把差值解释为每一项改动独立造成的收益。

红色与红注在这组样本中通关数相同，但后者到达底注 8 的局数更少；不隐瞒相同结果，也不为追求单调的表格反复挑选种子。

汇总数据见 `balance-results.json`；完整逐盲分数、金钱与最终小丑组合保存在本地 `.qa/balance-1.3.0-*.json`。这是初版调平依据，后续需要更多不同策略和实际玩家反馈；没有声称所有构筑强度相同或穷尽所有组合。
