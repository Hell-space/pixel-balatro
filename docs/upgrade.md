# 1.7.0 玩法与动效

1.7.0 新增两条单局规则、6 张原创小丑，改进选牌操作，并重做牌桌动画。原有牌型数值、Boss 规则、商店价格和存档都保留。

## Boss 破绽

每个 Boss 有一个固定的破绽牌型。选盲注时，Boss 卡片会显示“🎯 破绽：牌型 ×1.5”；对局中，Boss 说明栏、本局信息和图鉴的 Boss 页也会显示。

在 Boss 盲注中，如果打出的牌型正好是破绽牌型，所有小丑结算完后，最终倍率再 ×1.5。只看实际判定的牌型，例如破绽是“对子”时，打出两对或三条都不算。选中的牌组成破绽牌型时，预览栏会出现红色描边和“🎯破绽”标记，预计分数已经包含 ×1.5。

多人对决中双方面对同一个 Boss，因此破绽也相同。旧存档读取后，当前底注的 Boss 也会显示破绽并立即生效。

## 碾压奖励

击败盲注时，如果总得分达到目标分数的 2 倍或以上，结算多给金币：

| 得分 / 目标 | 奖励 |
| --- | --- |
| 2 倍到 3 倍以下 | $1 |
| 3 倍到 4 倍以下 | $2 |
| 4 倍及以上 | $3 |

结算明细中以“碾压 N× 目标”单列，并计入合计。多人模式下的小盲和大盲同样适用；Boss 对决按双方总分比较，不进入普通结算。

## 选牌操作

- **✦ 推荐**：预览栏左侧的按钮会枚举当前手牌所有 1–5 张组合，按保底得分（随机倍率取最小值）选出最高分组合，同分时少出牌。推荐会计入小丑、牌面强化、留手效果、节奏和破绽，并遵守通灵者必须出 5 张、独眼不能重复牌型的限制。推荐只帮你选牌，不会自动出牌。
- **滑动多选**：在一张手牌上按住，再滑过其他手牌，可以一次选中或取消一串。起点是未选中的牌时整串选中，起点已选中时整串取消；仍受 5 张上限限制。
- **计分牌高亮**：选中的牌里，会参与计分的牌发出金光，不参与计分的牌变暗。
- **牌堆**：牌桌左下角显示剩余牌数，点击打开剩余牌库。
- **键盘**：数字键 1–9、0 选择第 1–10 张手牌；H 推荐；S 切换按点数/按花色排序；Esc 取消全部选择。原有 Enter 出牌、X 弃牌保持不变。

## 动画

- 发牌：牌从左下牌堆飞出，在途中翻面。
- 手牌：宽屏时呈扇形；每隔几秒有一道轻微的波浪掠过手牌，其余时间保持静止，方便点击。选中时带回弹效果，鼠标悬停时卡牌朝指针倾斜并出现高光。
- 计分：牌面加成和小丑触发时迸出彩色像素粒子，筹码为蓝色，倍率为红色，金币为金色；“×倍率”会让倍率框放大并抖动。节奏连击、留手效果有飘字，打中破绽时盖“破绽！”印章并震动牌桌。
- 总分：总分和当前得分数字滚动增长；这一手打过目标时，预览栏发出火焰光，牌桌震动。
- 过关：盖“击破！”或“碾压 ×N！”印章，金币飞向金钱栏，结算明细逐行出现，合计金额滚动增长。失败时手牌坠落，牌桌褪色。
- 商店上新和刷新时，商品依次翻入；卡包候选依次弹出；盲注卡片依次滑入。标题页背景有花色缓慢飘过，小丑牌也会不时轻轻晃动。

计分速度设为“立即”时，计分相关的粒子、印章和数字滚动会跳过。系统开启“减少动态效果”时，所有装饰动画关闭。装饰动画使用独立的随机序列，不影响抽牌、商店或计分的随机结果。
