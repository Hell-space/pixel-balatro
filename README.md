# 像素小丑牌

用扑克牌型得分的 Roguelike 卡牌游戏，支持手机触屏、电脑和双人对战。单人版是自包含 HTML，无第三方运行时依赖。

**[打开游戏](https://hell-space.github.io/pixel-balatro/)** · [直接打开 HTML](https://hell-space.github.io/pixel-balatro/balatro.html) · [SVG 动画放映室](https://hell-space.github.io/pixel-balatro/gallery/)

## 游玩

手机浏览器直接打开游戏链接。竖屏使用两排手牌，横屏自动调整；点选最多 5 张牌后出牌或弃牌，长按查看效果。牌型预览计入牌面、强化与小丑效果；随机倍率以范围显示。

点击持有的小丑可以查看、卖出或左右调序。**小丑按从左到右的顺序结算，调整顺序会改变结果。** 点击消耗牌查看后使用或卖出，商店内也能操作持有的牌。需要选手牌的塔罗必须在对局中使用。五条、同花葫芦和同花五条有独立计分，对应星球在本局打出该牌型后才进入商店候选。

右上角菜单提供牌型表、牌库、计分明细、教程、独立音乐/音效开关，以及 1×、2×、4×、立即四档计分速度。键盘可聚焦手牌和按钮；焦点在牌桌空白处时 Enter 出牌，X 弃牌。弹窗打开后，Tab 留在当前弹窗内。

每个底注有小盲注、大盲注和 Boss。打过 8 个底注后可继续无尽模式；出局后可以回到该盲注前的保存点。

## 存档与离线

单人进度自动保存在当前浏览器，重新打开后选择「继续游戏」。1.2.0 兼容 1.1.0 存档，并保留上一份有效快照；主存档无法读取时会提供备份恢复。刷新可恢复手牌、次数、分数、商店和已打开的卡包；开包取消会退款并保留原候选，重复打开不会免费重抽。计分动画中途退出仍回到该次出牌前的稳定状态。

设置单独保存。存档不跨设备、浏览器或网址同步，清除网站数据会删除存档。多人对战不会覆盖单人进度，不支持整页刷新后继续多人局。

下载 `balatro.html` 后可直接打开，单人无需服务器或网络。手机能否打开本地 HTML、是否允许本地文件存档，取决于文件管理器和浏览器；在线链接最方便。游戏绘图、声音均由本地代码生成，不加载远程图片或字体。

## 本地运行与对战

需要 Node.js 18 或以上，不需要 `npm install`。

```sh
npm start
# 自定义端口
node server.js 8081
```

访问 `http://localhost:8080`。终端会打印局域网地址，同 Wi-Fi 手机可直接打开；系统防火墙需允许对应端口。

在「多人对战」填同一个服务器地址，一方创建房间、另一方输入房间码加入。每人 2 点生命，小盲和大盲各自闯关，Boss 关卡拼总分，低分方扣 1 点生命。

- 网络短暂断开有 **30 秒宽限**，浏览器自动重连并补收消息；超过宽限则结束本场。
- 主动退出会释放房间并通知对手；创建/加入请求期间取消也不会恢复后台连接。
- 消息校验、顺序发送和重试去重用于避免重复结算。服务仍是休闲中继，不提供权威防作弊、排行榜或账号。
- GitHub Pages 只运行静态游戏。联机需单独托管 `server.js`，HTTPS 游戏页需连接 HTTPS 服务；局域网 HTTP 服务可直接打开它提供的游戏页。
- `render.yaml` 保留原部署配置，端口支持 `PORT` 环境变量。已有服务更新时，应同时更新 HTML 和服务器代码。

## 开发与验证

修改 `src/` 后生成便携文件，一起提交。不要单独修改生成的 HTML。

```sh
npm run build
npm test
```

构建不下载依赖。`npm test` 验证生成文件一致性、牌型、全部 41 种小丑的独立计分样例、重复触发/调序以及 SSE 房间生命周期、消息回放与去重。

已具备 Python Playwright 和 Chromium 兼容浏览器时，可运行浏览器测试：

```sh
python tests/browser_smoke.py --browser "浏览器可执行文件的完整路径"
python tests/browser_extended.py --browser "浏览器可执行文件的完整路径"
```

支持 `BALATRO_BROWSER`；不指定则使用已安装的 Playwright Chromium。脚本使用无头隔离会话并自动启动/关闭本地服务，不读取个人浏览器资料。扩展测试包含明确标注的白盒夹具，用于罕见组合、旧档、终局和异常恢复，不把夹具当作完整正常游玩。

详情见 [验证记录](docs/verification.md)。截图和原始 JSON 写入被忽略的 `.qa/`。

## 目录

| 路径 | 用途 |
| --- | --- |
| `index.html` | GitHub Pages 游戏入口 |
| `balatro.html` | 构建生成、可直接打开的便携 HTML |
| `src/page.html` | 页面结构 |
| `src/table.css`、`src/layout.css` | 牌桌效果与响应式布局 |
| `src/jester.svg` | 像素小丑图案 |
| `src/js/score-engine.js` | 不改状态的计分计算，供预览和出牌共用 |
| `src/js/controls.js` | 弹窗、持有牌操作、设置与计分明细 |
| `src/js/session.js` | 存档校验、旧档兼容和备份 |
| `src/js/` 其他模块 | 定义、流程、动画、商店、教程、音频及联机 |
| `scripts/build.js` | 固定顺序拼装单文件 HTML |
| `server.js` | 零依赖静态入口与 SSE 中继；可单独导入做测试 |
| `tests/` | 规则、服务端与实际浏览器回归 |
| `gallery/` | 保留的独立 SVG 动画作品 |
