# 像素小丑牌

用扑克牌型得分的 Roguelike 卡牌游戏，支持手机触屏、电脑和可选的双人对战。页面、图形、音乐均由仓库代码生成；单人游戏不请求外部资源。

**[打开游戏](https://hell-space.github.io/pixel-balatro/)** · [直接打开 HTML](https://hell-space.github.io/pixel-balatro/balatro.html) · [SVG 动画放映室](https://hell-space.github.io/pixel-balatro/gallery/)

## 手机上玩

用手机浏览器打开上面的游戏链接。竖屏采用两排手牌，横屏自动调整牌桌。点选最多 5 张牌后出牌或弃牌；长按卡牌可看效果，长按不会触发选牌或购买。牌型表、牌库和教程在右上角菜单中。

单人进度保存在当前浏览器，重新打开后点「继续游戏」。已完成的出牌、弃牌、商店购买和结算会保存；计分动画或卡包选择过程中关闭，恢复到该操作之前的稳定状态。存档不跨设备、浏览器或网站地址同步，清除网站数据会删除存档。多人对战不提供续局。

也可以下载仓库中的 `balatro.html` 后直接打开，单人玩法无需启动服务器、安装依赖或联网。手机是否允许直接打开本地 HTML，以及本地文件的存档权限，取决于文件管理器和浏览器；在线链接使用最方便。

## 玩法

每个底注包含小盲注、大盲注和 Boss 盲注，完成 8 个底注后可继续无尽模式。利用弃牌凑成对子、同花、顺子等牌型得分，在商店购买小丑牌、星球牌、塔罗牌、卡包和优惠券。Boss 带有额外限制；出局后可以回到该盲注前的保存点重试。

电脑支持点击选牌；焦点在牌桌空白处时 Enter 出牌，X 弃牌。按钮与手牌支持键盘聚焦，选中的手牌同时通过边框、位置和 `aria-pressed` 表示。

## 本地运行与双人对战

需要 Node.js 18 或更高版本，无第三方运行时依赖。

```sh
npm start
# 自定义端口
node server.js 8081
```

浏览器访问 `http://localhost:8080`。服务启动后会打印局域网地址；手机与电脑连接同一网络时，使用该地址打开游戏。系统防火墙需要允许所选端口。

双人对战需要双方能访问同一个 `server.js` 服务：进入「多人对战」，填入服务地址，一方创建房间，另一方输入房间码加入。每人 2 点生命，小盲注和大盲注各自闯关，Boss 关卡比较总分，低分方扣 1 点生命。该服务是休闲游戏消息中继，不提供排行榜、防作弊或断线重连。

GitHub Pages 只托管静态网页，不运行联机服务。从 HTTPS 游戏页连接时，对战服务也须使用 HTTPS；局域网 HTTP 服务可以直接用其提供的游戏页游玩。仓库保留 `render.yaml`，可按自己的托管方案运行 Node 服务，`PORT` 环境变量用于指定端口。

## 修改和验证

编辑 `src/`，再重新生成便携 HTML；不要单独修改生成文件，否则后续构建会覆盖。

```sh
npm run build
npm test
```

`npm test` 检查源码与便携文件一致，并测试基础牌型、A2345、万能牌、升级与燧石 Boss 的基础数值。构建不下载依赖。

已有 Python Playwright 与 Chromium 兼容浏览器时，可运行真实浏览器回归：

```sh
python tests/browser_smoke.py --browser "浏览器可执行文件的完整路径"
```

也可通过 `BALATRO_BROWSER` 指定浏览器；不指定时使用已安装的 Playwright Chromium。脚本在无头独立会话中启动本地服务，检查手机和桌面操作、计分、商店、续局、独立 HTML 和双客户端联机。截图及报告写入被 Git 忽略的 `.qa/`，不会使用个人浏览器资料。

验证范围和已知限制见 [验证记录](docs/verification.md)。

## 目录

| 路径 | 用途 |
| --- | --- |
| `index.html` | GitHub Pages 游戏入口，转到便携 HTML |
| `balatro.html` | 可直接打开的单文件游戏，由构建脚本生成并随仓库提交 |
| `src/page.html` | 页面结构 |
| `src/table.css`、`src/layout.css` | 基础牌桌效果与响应式布局 |
| `src/jester.svg` | 代码绘制的像素小丑图案 |
| `src/js/` | 牌库定义、流程、计分、商店、教程、联机、存档与音频 |
| `scripts/build.js` | 按固定顺序拼装自包含 HTML |
| `server.js` | 零依赖静态入口与 SSE 联机中继 |
| `tests/` | 规则测试与真实浏览器回归脚本 |
| `gallery/` | 保留原有 SVG 动画作品，与游戏入口分开 |
